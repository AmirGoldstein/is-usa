# Strengthening Jewish Life on Campus

A single-page website supporting Jewish students at NYU and across New York City, bringing an authentic Israeli voice for understanding, dialogue, and community.

## About

This project presents a mission statement and personal story aimed at strengthening Jewish life on campus during challenging times. It features a clean, professional design optimized for both web viewing and printing.

## Tech Stack

- **React 18** - Modern UI library
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework

## Getting Started

### Prerequisites

- Node.js 18+ or Bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173` to view the site.

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` folder, ready for deployment.

## Deployment to GitHub Pages

1. Build the project: `npm run build`
2. Deploy the `dist` folder to GitHub Pages
3. Ensure your repository settings point to the correct branch/folder

## Features

- **Print-Optimized**: The page is designed to be printed as a professional flyer
- **Responsive Design**: Works on all screen sizes
- **Clean Typography**: Uses Google Fonts (Source Sans 3 & Source Serif 4)
- **Professional Layout**: A4 page format with proper spacing and hierarchy
